Install once. Opt in per project.

Download and extract the v1.1.0 source ZIP above, then open a terminal in the extracted directory. Use Node 22.13 or newer. Windows with Node 24.15.0 and Codex runtime 0.160.0 is the current verification environment; other platforms are not yet tested. Installation preserves unrelated hooks, pins Node and creates transaction backups. Review and trust definitions in Codex before relying on them.

node install.mjs --dry-run
node install.mjs
node init-project.mjs C:/dev/my-project --example agent-build

Registration: CODEX_HOME/hooks.json. Project policy: .codex/hook-kit.json. No project policy means the kit stays silent. The initializer never overwrites an existing policy without --force.

Know what a gate proves.

A file count does not prove someone understood or reused the code. A fresh receipt does not prove the reported result is true. These are observable workflow checks, with documented gaps—not a substitute for review or an access-control sandbox.
